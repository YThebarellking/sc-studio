## SC Studio 2.4-feature-update.3

Первичная публикация предоставленного исполняемого JAR.

### Сведения о сборке
- Требуется Java 17 или новее.
- Формат: `sc-studio_test.jar`.
- Встроенная заметка версии упоминает ZIP-архивы проектов, текстуры отдельных Shape и объединение атласов.

Эта публикация содержит готовый бинарный файл; исходный код и воспроизводимая процедура сборки не входят в репозиторий.
